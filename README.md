Assignments from INFO135 Advanced Programming at UiB.

- Data structures and algorithms
- Object-oriented programming
- Thread programming
- Algorithm efficiency analysis
- Structured data formats (JSON, RDF, XML)

### Oblig 2 – Data Structures
- Jupyter Notebook exercises
